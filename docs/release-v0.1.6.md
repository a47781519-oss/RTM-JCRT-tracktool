# v0.1.6

## 更新内容

**新增日文本地化**：加入 ja_jp.lang，123 个键与英文语言文件逐键对应（占位符全部保留）。游戏语言设为「日本語」即可全界面显示日文。

**解析几何单条线长度上限 2000 m → 4000 m**：点数上限（1024 点）与线长无关，所以线变长不会撑大网络包，只是采样间距按 长度/1023 变粗。R=300 m 时的弦高误差：2 km 约 1.6 mm、4 km 约 6.3 mm，都在看不出来的范围内。

**文档**：新增英文版 README（README.en.md）与日文版 README（README.ja.md），三种语言互相跳转；英日文档里补充了 GB 50090（中国铁路线路设计规范）各项数值的出处说明。

- 前置：RealTrainMod 2.4.24 + NGTLib 2.4.21
